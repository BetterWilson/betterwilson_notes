


## `if __name__ == "__main__"`

每个模块都有`__name__`属性，用于标识模块的“名称”：

- 当模块被导入时，`__name__`的值是模块名（如math）
- 当模块自身被执行时，`__name__`的值是`__main__`

**核心原理（怎么工作的）**

- 每个 Python 文件都有一个内置变量 `__name__`。
- 当直接运行这个文件时，Python 会自动把该文件的 `__name__` 变量设为 `"__main__"`。
- 当在别的文件里导入这个文件时，Python 会把该文件的 `__name__` 变量设为它的文件名。

所以，`if __name__ == "__main__":` 这行代码就是在问：“我现在是被直接运行的吗？”当你写一个工具类或函数库时，可以在下面写一些调试测试代码。别人 `import` 你的模块时不会运行这些测试，只有你自己直接运行这个文件时才会执行，互不干扰



## 模块的其他属性

- file属性：每一个模块都有一个内置属性`__file__`可以查看模块的完整路径

- all属性：如果一个模块文件中有`__all__`变量，当使用`from xxx import *`导入时，只能导入这个列表中的元素
